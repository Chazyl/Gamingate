## Getting help

- **Questions / ideas / show-and-tell:** open a
  [GitHub Discussion](https://github.com/Chazyl/Gamingate/discussions).
- **Bug reports:** use the
  [bug report template](https://github.com/Chazyl/Gamingate/issues/new?template=bug_report.yml).
- **Feature requests:** use the
  [feature request template](https://github.com/Chazyl/Gamingate/issues/new?template=feature_request.yml).

When reporting a problem, please include your OS and version, whether you used a
packaged build or a source build, the provider you were using, and any relevant
console/terminal output (redact anything personal).

## Security

Do **not** file security issues publicly. See [SECURITY.md](SECURITY.md).

## Scope

This project is an independent, unofficial client. Support covers the gateway
software itself — not the cloud-gaming providers' accounts, catalogues, or
availability.
